# Architecture

## System overview

The device is a **standalone WiFi appliance**. It's built to keep working when moved away from the PC (e.g. a kitchen).

| Feature | Source | Needs PC? |
|---|---|---|
| Clock | NTP over WiFi *(Milestone 4; currently build time)* | No |
| Weather | Open-Meteo over WiFi *(Milestone 4; currently demo data)* | No |
| Calendar | Google Calendar *(Milestone 4+; access method TBD; currently demo data)* | No |
| Countdown timer, focus timer | On-device | No |
| PC stats, media controls | Optional Windows companion over USB serial | Yes |

## Firmware layout (`firmware/`)

```
include/ + src/
  board_cyd.*            Pin map, backlight, RGB LED (hardware only)
  theme.h                Design tokens: colours, spacing (RGB565 from hex)
  settings.h             User preferences (12/24 h, °F/°C, idle timeout)
  model.*                Central app state: weather, calendar (+ version counters)
  timefmt.*              Local time + display formatting ("in 2h 15m", "Friday, Nov 7")
  demo_data.*            Sample data + build-time clock until real sources exist
  touch_input.*          XPT2046 on VSPI: 100 Hz sampling, debounce, smoothing, events
  touch_calibration.*    Affine calibration fit + NVS persistence
  calibration_screen.*   4-corner + centre-verify calibration UI
  ui/ui.*                Fonts, flicker-free sprite regions, text fitting, colours
  ui/icons.*             Anti-aliased vector weather icons (WMO codes)
  ui/widgets.*           Header + back button, chevron buttons, ButtonGroup press logic
  ui/screen.h, nav.cpp   Screen interface + navigator (back history, idle return, lockout)
  screens/*              Home, Calendar, Apps launcher, Settings, placeholders,
                         dev screens (calibration, touch test)
  fonts/*.h              GENERATED by tools/make_fonts.py (Inter, SIL OFL)
```

### Main loop

`loop()` calls `ui::nav::loop()` only. Nothing blocks.

1. `touch_input::poll()` samples the panel at 100 Hz and queues events
   (`Press`, `Move`, `Release`, `Tap`, `LongPress`). The navigator sends them to the active screen.
2. The active screen's `update()` runs. It redraws only regions whose data changed
   (the minute ticked, or a model `version` counter moved).
3. Screen changes requested with `nav::go()` / `nav::back()` are applied *after* the
   iteration, never mid-draw. `back()` follows a small history stack (cleared on Home);
   non-Home screens return Home after `IDLE_RETURN_MS` without touches.

### Navigation map

```
Home --tap clock / long-press--> Apps --> Calendar | Weather | Focus | Timer | Music | PC | Settings
Home --tap Up Next card-------> Calendar           Settings --> Recalibrate touch | Touch test
Home --tap weather------------> Weather
```

### Rendering rules

- Dynamic regions are painted into an off-screen sprite and pushed in one transfer
  (`ui::region`), so there's no flicker. If memory is short it falls back to drawing
  through a viewport.
- Text uses anti-aliased Inter fonts in five sizes (Clock 60, Temp 40, Title 22,
  Body 16, Label 13). Layout aligns text on **baselines** shared across columns.
- Weather icons are vector-drawn into sprites (anti-aliasing reads back from the sprite).
- Touch targets act on **release inside** (or `Tap`). A screen ignores a `Release` that
  started on a previous screen, so one gesture can never trigger two screens.
- Demo data is always labelled on screen.

### Data flow

Data sources write into `model::state()` and increment that section's `version`.
Screens remember the version they last drew and redraw when it changes. Future WiFi
fetchers and the optional PC link plug in as additional writers without touching the screens.

## Tools

- `tools/make_fonts.py`: converts TTF into TFT_eSPI smooth-font (VLW) headers and
  writes `assets/fonts/preview.png` decoded from the generated bytes.
  Run with the project venv: `.venv/Scripts/python tools/make_fonts.py`
  (setup: `python -m venv .venv && .venv/Scripts/pip install pillow`).
- `firmware/scripts/upload_wait.py`: makes esptool wait for BOOT (see hardware.md).
